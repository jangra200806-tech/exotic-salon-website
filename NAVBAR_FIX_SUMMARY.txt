NAVBAR FIX - COMPLETE
=====================

ISSUE REPORTED:
- Dropdown links (All Services, Men, Women, Bridal, Photos, Videos) appearing 
  horizontally instead of vertical list
- This caused navbar layout to break - Services and Gallery pushed upward
- Home and Contact sequence appeared messed up
- Blue underlines appearing on navbar links

ROOT CAUSE:
The initHeader() function in js/script.js used jQuery $ selectors 
but jQuery was not included in the HTML files, causing JavaScript failures.
Additionally, the dropdown link CSS was not properly forcing vertical layout.

FIXES APPLIED:

1. JAVASCRIPT FIX (js/script.js):
   - Rewrote initHeader() to use vanilla JavaScript document.getElementById()
   - const header = document.getElementById("siteHeader")
   - const burger = document.getElementById("hamburger")
   - const menu = document.getElementById("mobileMenu")
   - This eliminates the jQuery dependency issue

   - Removed all underlines (text-decoration: none applied)
   - Fixed link color and hover states

     min-width: 200px, proper shadow and background

     (forces vertical list layout, not horizontal)
   - .nav-dropdown a: color: var(--charcoal), padding: 10px 12px,
     transition: all 0.2s ease, hover background effect
   - .nav-item.has-dropdown:hover .nav-dropdown: display: flex, 
     opacity: 1, visibility: visible (show on hover)
